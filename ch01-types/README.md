## 🎯 目标
- 用 `struct` 表达数据载体，理解它是**真值类型**（栈上连续、无对象头）。
- 分清值接收者 vs 指针接收者（高频坑）。
- 分清值语义 vs 引用语义（slice/map/channel 是引用的例外）。
