## 📊 Java 25 → Go 对照表（雏形，带教时展开）
| 维度 | Java 25 | Go |
|---|---|---|
| 主力 GC | G1 / ZGC（分代、亚毫秒）/ Shenandoah（JEP 521） | 并发三色标记清除（非分代、非压缩） |
| STW | 亚毫秒 | 通常亚毫秒 |
| 调优 | 一堆 `-XX` | `GOGC` + `GOMEMLIMIT`（1.19+） |
| 内存布局 | 对象头 + 引用数组（指针追逐） | struct 连续布局、无对象头、slice 连续内存 |

> 关键洞察：现在 Go 的真实优势是"开箱即得的可预测低延迟 + 更低内存 + 几乎不用调 GC"；Java 优势是吞吐更高、工具更成熟、旋钮更多。按 QPS/延迟目标权衡，不迷信。
