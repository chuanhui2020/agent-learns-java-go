# Ch04 实验报告模板

复制本文件为 `lab-<主题>.md`，先填写预测，再运行实验。模板本身不是实验完成证明。

## 环境

- 日期、CPU、OS / 架构：
- `go version`、`go env GOOS GOARCH CGO_ENABLED`：
- `java -version`、JVM 参数：
- 代码版本 / 工作区改动、内联设置、采样时长与次数：

## 预测（运行前填写）

- 预期输出 / 分配趋势：
- 依据的 Go spec / JLS 条款：
- 哪些判断属于规范保证，哪些只是实现假说：

## 方法与原始数据

- 代码路径和完整命令：
- 标准输出 / 编译器诊断：
- 基准至少重复 10 次；记录 ns/op、B/op、allocs/op。比较耗时变化时附 benchstat 统计，不把单次跑分快慢当成结论。
- 初始化实验每次启动新进程；Java 类初始化失败后不能在同一个类加载器里“重试成功”。

## 结论与有效性威胁

- 数据支持 / 推翻了哪些预测：
- 偏差如何用捕获、接收者求值或初始化机制解释：
- 内联、常量折叠、计时循环成本、CPU 频率和平台差异的影响：
- 不从本机零分配推出其他 Go / JDK 版本也零分配；不以单线程结果证明并发安全。
